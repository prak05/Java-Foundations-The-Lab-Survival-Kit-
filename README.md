## 🎓 Project Overview

**Java Foundations: The Lab Survival Kit** is a curated collection of Java lab programs illustrating:

- Core programming challenges  
- Object-Oriented Programming pillars  
- Algorithmic problem solving  

Each program is **well-commented**, demonstrating best practices to help learners understand concepts clearly.

## 🚀 Quick Start

1. **Clone the repository**  
   ```
   git clone https://github.com/prak05/Java-Foundations-The-Lab-Survival-Kit-.git
   cd Java-Foundations-The-Lab-Survival-Kit-
   ```

2. **Compile & Run**  
   ```
   # Compile
   javac 1-palindrome.java
   # Run
   java 1-palindrome
   ```
   Replace filenames/class names as needed.

## 📚 Core Programs

### 1. Palindrome Checker (`1-palindrome.java`)
- Checks if input string/number reads the same backwards.  
- **Concepts:** Loops, string manipulation.

### 2. Frequency Counter (`2-frequency.java`)
- Counts occurrences of characters/elements in array.  
- **Concepts:** Arrays, nested loops.

### 3. Smallest Number Finder (`7-smallest_no.java`)
- Identifies smallest value from inputs.  
- **Concepts:** Conditionals, comparison operators.

---

## 💡 OOP Demonstrations

### 8. Method Overloading (`8-ovrld.java`)
- Multiple methods same name, different parameters.  
- **Concepts:** Compile-time polymorphism.

### 10. Abstraction (`10-abstraction.java`)
- Abstract classes/methods hide implementation.  
- **Concepts:** Abstraction, inheritance structure.

### 11. Inheritance (`11-inheritance.java`)
- Subclass inherits parent class features.  
- **Concepts:** Code reuse, extends keyword.
